# Prompts Used During Development

## System / Architecture Blueprint
The application layout, structure, and features were initiated using a comprehensive structural instruction inside Cursor Composer:

```text
Create a comprehensive, modern React application for a Student Dashboard. 

Requirements:
1. Initialize a clean, lightweight React structure inside a folder named "student-dashboard-app".
2. Layout: Sidebar navigation containing tabs for Dashboard, Courses, Tasks, Grades, and Announcements.
3. Statistics Section: Quick-view metrics cards showing Current GPA (3.8), Total Credits Earned (45), Enrolled Courses (4), and Upcoming Assignments (3).
4. Interactive Tasks Component: A React state-driven To-Do Task list where students can type a task title, select a due date, assign a priority tag (High/Medium/Low), and add it to a list.
5. Grade Analytics Section: A visual breakdown table or mock progress bars showing letter grades and percentages for current classes (e.g., Computer Science: A/94%, Calculus: B+/88%).
6. Announcements Notice Board: A modern card component displaying 2-3 mock campus notifications (e.g., "Library hours extended for finals week", "System maintenance on student portal this Sunday").
7. Theme & Styling: A beautiful, responsive, and professional academic dashboard UI with clean spacing and a trustworthy modern color palette.
```
