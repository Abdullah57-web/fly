# Student Portal Project Rules

## Development Rules
1. Form Fields: All profile data collection forms must explicitly define input requirements for Student ID (alphanumeric pattern checking), Full Name, Institutional Email (.edu suffix check), and Complex Passwords.
2. Error Handling: Front-end form validations must never use generic alerts; they must render immediate context-specific error text wrappers natively beneath the targeted invalid entry node.
3. Verification: JavaScript form-processing architectures must contain structured code blocks with explicit validation check comments defining where validation conditions execute.
